# Yo Pongo El Tip

A simple and elegant tip calculator web application.

## Features

- **Input Bill Amount**: Type in the total amount of your bill
- **Horizontal Slider**: Scroll left to right to select tip percentage (0-30%)
- **Real-time Calculation**: See tip amount and total instantly
- **Responsive Design**: Works on desktop and mobile devices
- **Beautiful UI**: Modern gradient design with smooth animations

## How to Use

1. Open `index.html` in your web browser
2. Enter the bill amount in the input field
3. Adjust the tip percentage using the horizontal slider
4. The tip amount and total will be calculated automatically

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
